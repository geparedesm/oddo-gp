Job Pilot — Career Profile

Maintain a structured career profile and import data from uploaded CVs.

Overview

Job Pilot lets each internal user maintain a complete career profile: personal information, professional title/summary/attributes, skills, work experience with projects and achievements, education, certifications, languages, leadership & volunteering, references and free-form additional information.

CV Import Workflow

Upload a CV (PDF or DOCX) against a profile and run it through a controlled four-step workflow:

  1. Extract — pull raw text out of the PDF/DOCX file.
  2. Parse — detect contact details, professional summary, skills and languages, proposing each as a reviewable change.
  3. Review — a human decides, line by line, whether to keep existing data or apply the proposed value; duplicate skills/languages are flagged and default to "keep" so nothing is overwritten silently. Anything the parser could not confidently classify is listed separately as Unclassified Information for manual handling.
  4. Import — once every line has an explicit decision, the accepted changes are applied to the profile.

Safety

Existing profile data is never overwritten automatically. Every conflicting field or duplicate record defaults to "Keep Existing / Skip" and requires an explicit reviewer decision before import.
